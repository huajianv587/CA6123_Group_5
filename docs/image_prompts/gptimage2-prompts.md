# GPTImage2 Visual Prompt Pack

These prompts define the visual direction for the README image set. The final committed diagrams use the same visual language, with critical labels rendered locally so that GitHub displays readable text instead of AI-generated microtext.

## Shared Style

Use this style anchor for every image:

> Enterprise SaaS operations platform, modern customer service command center, clean academic infographic, dark navy and emerald accent, high-end product documentation style, realistic but not cluttered, no tiny unreadable text, 16:9, professional, suitable for university project README.
